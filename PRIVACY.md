# Privacy

Soft Recall Demo is a static browser game. The game has no account system, backend, database, or built-in analytics.

## Local Data

Progress and accessibility settings are stored only in the browser's local storage. Players can remove that data by clearing site data in their browser or by restarting the demo from its in-game controls.

The optional run-log download is created locally after a player requests it. The game does not upload that file.

## Hosting

The public game may be hosted by itch.io or GitHub Pages. Those services can process technical information under their own privacy policies. Soft Recall Demo does not receive that hosting data through the game.

## Contact

Use the support process in [SUPPORT.md](SUPPORT.md) for privacy questions or reports.
