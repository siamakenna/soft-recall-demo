# Playtest Guide

Use this guide with three to five desktop players before a public version update. Let the player explore without coaching unless progress has stopped completely.

## Setup

- Use the public itch.io URL in a private browser window.
- Record browser, operating system, screen size, and whether fullscreen was used.
- Ask the player to think aloud only when it feels comfortable.
- Do not explain the intended meaning of a scene before play.

## Observe

- Time from Title to Ending
- First object selected in each room
- Any moment when the next action is unclear for more than 30 seconds
- Whether Doorways are noticed and understood
- Whether the phone puzzle and routine interactions can be completed without help
- Whether Memory Book is opened voluntarily
- Ending reached and whether its cause feels understandable
- Keyboard focus, readability, or motion discomfort

## Ask Afterward

1. What do you think happened during this morning?
2. Which moment felt most clear or memorable?
3. Where did you feel stuck, and what did you try?
4. Did any cue feel helpful without feeling like a tutorial?
5. Did the ending feel connected to your choices?
6. What would you remove before adding anything new?

## Record

For every issue, note the room, action, expected result, actual result, and whether the player recovered without assistance. Attach a screenshot or short screen recording when placement or timing matters.

Do not collect names or health information. Playtest notes should describe the game session, not infer anything about the player.
