# Versioning

Use lightweight demo version labels until the project needs formal semantic versioning.

Suggested labels:

- `v0.1`: static demo foundation.
- `v0.2`: core playability and professional repo structure.
- `v0.3.0`: cinematic desktop demo with tactile routines, room stories, and bounded eerie atmosphere.

The package version, changelog, Git tag, and itch.io ZIP use the same version.
Keep release ZIPs outside the source tree and retain the previous public ZIP for rollback.

Avoid labeling exploratory branches as releases until the required PC route passes.
