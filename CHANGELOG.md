# Changelog

## Unreleased

## 0.3.0 - 2026-09-14

- Added four optional room stories and six silent, skippable camera films using the existing paintings.
- Added pointer dragging for notes, keys, tea, toast, and recall sorting, plus brushing gestures and faster room transitions.
- Added adaptive recall, a complete-route cinematic, and a saved Memory Book review before the final checks.
- Added state-driven haze and an optional frustration response, remembered across reloads.
- Fixed Enter/Space activation of focused hotspots and made motion/distortion settings control the atmosphere effects.
- Fixed camera pointer tracking and registered hotspot targets to the actual scene image during pan, zoom, and desktop aspect-ratio changes.
- Fixed Escape from settings sliders and prevented the frustration prompt from interrupting another interaction.
- Gave recall/readiness drop areas dedicated placement buttons so clicking the fallback cannot remove a previously sorted card.
- Added complete keyboard-route and cross-browser checks, desktop screenshots, and release evidence.
- Preserved the shorter route and three endings; the 20-30 minute exploratory route remains a playtest target.
- Added a reproducible itch.io packaging workflow and public release guide.
- Added a desktop viewport safeguard for constrained browser embeds.
- Reduced scene download size by converting unchanged scene artwork to WebP.
- Bundled the game fonts locally and added social preview metadata.
- Removed unused UI scaffolding, dependencies, and trailer copies from the deployed app.
- Moved verified research notes behind the optional Memory Book Learn More tab and tightened claim boundaries.
- Added privacy, credits, and structured playtest documentation.
- Added professional repository documentation files.
- Added CI workflow for pull requests and manual dispatch.
- Added GitHub issue templates, pull request template, Dependabot configuration, and support/security/contributing docs.
